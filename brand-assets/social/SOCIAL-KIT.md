## 4. Setting up (things only you can do, signed in)

1. **Instagram**: switch to a Professional → Business account, category "Clothing (Brand)". Put the bio and link above,
   upload the profile picture, add the Highlights.
2. **Facebook page**: Profile picture, cover, Intro, About, Website, contact. Add the **Shop now** button → lupinwear.store.
3. **Link Instagram to the Facebook page** (Page settings → Linked accounts) so posts can be shared to both.
4. **TikTok**: switch to a Business account so the link in the bio works. Then put the TikTok link in the store:
   Dashboard → Content → Footer contact → TikTok link: `https://www.tiktok.com/@lupin.wear.eg`
   (with `https://` at the start; the site ignores links without it).
5. **Meta Catalog — done 2026-11-19.** Business portfolio **Lupin | Menswear** (ID 29984096994525504, created by Meta when
   Instagram was connected) holds the catalogue **LUPIN Store** (ID 1603950748435756), fed hourly from
   `https://lupinwear.store/catalog/meta.csv`, and the Pixel **lupinwear.store** (ID 1790053122102572), which the store now
   uses (Dashboard → Settings → Ads tracking). The old Pixel 508091083934676 sat on a restricted personal ad account and
   could not be connected. The Conversions API token for this Pixel is saved on Render as `META_CAPI_TOKEN`
   (2026-11-19), so the server also reports each Purchase. Generating a token needs an email on your profile in the
   portfolio (Business info → Profile contact info: lupin.wear.eg@gmail.com).
