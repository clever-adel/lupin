# LUPIN WEAR

E-commerce platform for LUPIN. (`lupinwear.store`) — Egypt, EGP, English + Arabic.

| Path | What |
|---|---|
| `backend/` | Spring Boot 3.5 / Java 21 modular monolith, PostgreSQL, Flyway |
| `frontend/` | React Router 7 (SSR) on Cloudflare Workers, Tailwind 4 |
| `brand-assets/` | Owner-supplied master logo files — do not edit |
| `tools/` | `derive-logo-assets.py` regenerates `frontend/public/brand/` from the master logo |
| `docs/` | Audit, architecture, ERD |

Start with `IMPLEMENTATION_STATUS.md` (what works, what does not, how to run it) and `DECISIONS.md`.

This project is **not production-ready**; the status file lists everything outstanding.
